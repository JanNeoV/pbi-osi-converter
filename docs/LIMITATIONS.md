# Limitations

- The 46/21/25 findings apply only to the captured `pbi_trial` model and
  Snowflake YAML.
- Runtime equivalence is `NOT_AVAILABLE`; the audit does not claim runtime
  mismatches without comparable result evidence.
- The 7/7 relationship result compares endpoint topology and compatible
  many-to-one intent. It does not prove complete model or query equivalence.
- Later demonstrations use synthetic fixtures. Their counts are not the
  captured conversion benchmark.
- Filter-state, visual-scope, relationship-manipulation, and transitive unsafe
  dependencies remain manual review; the POC does not claim 1:1 translations.
- The POC is not a universal DAX converter.
- The scripted provider demonstrates bounded agent orchestration, not the
  behavior of every language model.
- Review memory is exact, evidence-backed, and confirmation-required. It is not
  automatic model training or unrestricted cross-model learning.
- The documented ingestion workflow creates a semantic view from an uploaded
  Power BI file; this repository demonstrates a governance layer, not a claim
  that Snowflake offers no other integration path.
- No public command approves, applies, verifies against a live account, or
  deploys a target.
- The checked agent demonstration is scripted and offline. A provider-backed
  smoke and live-account validation remain separate and are not claimed.
