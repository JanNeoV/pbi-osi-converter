# Prioritized follow-up milestones

1. **Interchange regression evidence.** Minimize the time-spine/entity/filtered-metric
   losses, confirm upstream intended behavior, and prepare a narrowly scoped regression
   test or documentation change. If a separately labeled configuration-restoration
   adapter is evaluated later, keep the unmodified conversion path as its own case.
   Acceptance: at least one returned-manifest query actually executes, with every
   adapter intervention recorded. Add broader fixture coverage only for distinct risks.
2. **Optional official Power BI validation.** Pin and document TOM/.NET setup in an
   optional environment, serialize copied artifacts to TMDL and validate references.
   Follow with an independently scoped DAX engine experiment on the same data; preserve
   the account-free core. Acceptance: distinguish serialization, model validation,
   engine compilation and numerical execution in evidence. No deployment is automatic.
3. **Agent evaluation integration.** Implement the governed/direct-SQL experiment in
   conjunction with the existing AI agent evaluation lab, using the
   [feasibility specification](AGENT_FEASIBILITY.md). Acceptance: frozen comparable
   configurations, unseen synthetic questions, independent ground truth and provenance.

A new application, dashboard, vector store or agent orchestration framework is not
needed for any of these milestones.
