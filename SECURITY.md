# Security policy

This repository is an offline proof of concept. Do not place credentials,
account locators, profiles, `.env` files, live query results, or production
Power BI state in issues, pull requests, or demo artifacts.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting feature for this repository. Do
not include secrets or production data in the report. If private reporting is
not enabled yet, open a minimal issue asking the maintainers to enable a private
channel without disclosing the vulnerability.

## Supported version

Only the latest tagged release is supported. Public demo commands must remain
offline, proposal-only, and deployment-free.
